A Black Friday / Cyber Monday deal finder with 25 real deals, each found and price-checked by an AI agent on 27 November 2026 in a deals source that names the store. Every card shows the product, store, store link, sale price, usual price, computed discount, when the price was checked, and an honest verdict — New low, Strong deal, Good deal, Modest, or Check the reference (for strikethrough prices that were never selling prices). Search, filter by category / store / discount, and sort by verdict, discount, saving or price. Pure static files, zero network requests at runtime.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

## Build the entry dossier

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
